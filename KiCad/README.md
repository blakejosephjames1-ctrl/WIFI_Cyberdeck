## About
This folder contains all of the KiCad files for my project the files here are for the Micro controler for my project. My final product will consist of a microcontroler touchscreen battery and case however the KiCad files here only contain the microcontroler. The touch screen will be attached through GPIO pins and the battery through the designated connections so i did not have anything to include in the KiCad files for these components. The board has additiional memory so that heavyer weight opperating systems and programs can be ran on the device expanding the deviecs capabilitys.
