# About Project
This project is a Cyberdeck -style WiFi experimentation and penetration testing device based on an ESP32 -s3 microcontroller. Desighned on KiCad.




The device is commpatible to run EPS32 marauder https://github.com/justcallmekoko/ESP32Marauder.git (NOT TO BE USED FOR UNAUTHORISED PEN-TESTING)
