# About Project
This project is a Cyberdeck -style WiFi experimentation and penetration testing device based on an ESP32 -s3 microcontroller. Desighned as an entry for Hack Club's blueprint https://blueprint.hackclub.com/




The device is commpatible to run EPS32 marauder https://github.com/justcallmekoko/ESP32Marauder.git (NOT TO BE USED FOR PEN-TESTING WITHOUT PERMISION)
